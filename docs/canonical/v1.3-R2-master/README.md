## Scope rule

v1.3/v1.4 remain **Interview-first**. The Personal Conversation Intelligence chapter is a retained future profile and shared-core constraint, not permission to add a Meeting top-level navigation or claim v2.0 implementation.

## Runtime truth rule

When design text and current runtime evidence diverge:

1. current runtime / DB / release artifact / CI evidence,
2. this canonical master,
3. frozen v1.2-R2 technical/governance core,
4. earlier documents.

Implementation reports must state the divergence rather than silently rewriting either side.
